Single-line Suggestion

Students get one line of inline ghost-text at a time as they type, like GitHub Copilot. Tab accepts.

Multi-line Suggestion

Agent skills

Optional instructions the agent follows for students in the AI Agent condition (e.g. "Explain every change in beginner terms"). Students can turn these on or off and add their own.

Bug skills

Every AI code suggestion and agent change is shown to students as options in random order: one correct, and one or more with exactly one bug each. For each buggy option the AI picks a selected bug type below that fits the code and follows its instructions; no two buggy options of a suggestion share a bug type. Each bug is a .md file: edit it here, download it, or upload your own. Students never see these. If none is selected, students get a single correct suggestion. How many buggy options students see and what happens when they accept one are set per problem, in the Problems step.

AI bugs for Problem 1

How AI suggestions with bugs work for students on this problem.

How many buggy options students see next to the correct one, each with a different bug type (e.g. option B has an API error, option C an off-by-one). Needs at least that many bug types selected in the Bug skills step; with fewer, students get one buggy option per selected type. 1 option: randomly correct or buggy: students see a single suggestion, like a plain code assistant, which is the correct one or one with a bug, at random (half the time each).

Correct wrong picks

On: when a student accepts the option with the bug, they are told right away, shown why it is wrong, and their code is switched to the correct option before they continue. Off: their code is left as they accepted it.

Show correct answer

On: when a student accepts the option with the bug, they are told it had a bug and shown why and the correct code, but their code is not changed: fixing it is up to them. Off: students are never told which option was wrong and get no explanation.
